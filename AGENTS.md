# Инструкции для агентов

«Кто перед вами» — тренажёр отношений и типов личности: Telegram Mini App и сайт. Стек: Node 22, Express, фронтенд на чистом JS (ESM, без сборки), тесты `npm test` (`node --test`). Деплой — Render (`render.yaml`).

## Портреты и любые картинки персонажей

Перед генерацией любого портрета прочитай [docs/portraits-brief.md](docs/portraits-brief.md) и следуй ему полностью. Там референс стиля, промпт-шаблон, требования к файлу и проверка.

Самое важное:
- к каждой генерации прикладывай `public/img/archetypes/dark-empath.webp` как референс стиля;
- используй промпт-шаблон из брифа без изменений стилевого блока.

## Общие правила

- В этой папке параллельно работают несколько агентов. Коммить только свои файлы (`git add <файлы>`), никогда не используй `git add -A`, и проверяй `git status` перед коммитом.
- Секреты (ключи API, токены бота) не пишутся в код, коммиты и чат. Они лежат только в переменных окружения.
- Архетипы описаны в `public/js/archetypes.js`. Новый тип требует согласованных правок в квизе, кейсах, персонажах, лаборатории и дуэли; тесты в `test/` проверяют, что всё сходится.
