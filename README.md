# Кто перед вами

Тренажёр общения для комьюнити (веб + Telegram Mini App): 12 трендовых архетипов, у каждого — научный конструкт и источники.

| Архетип | Научная основа |
|---|---|
| Тёмный эмпат | Тёмная триада + эмпатия (Heym et al., 2021) |
| Грандиозный нарцисс | Грандиозный нарциссизм, модель NARC (Back et al., 2013) |
| Уязвимый нарцисс | Уязвимый нарциссизм (Hendin & Cheek, 1997) |
| Макиавеллист | Макиавеллизм (Jones & Paulhus, 2014) |
| Психопат | Триархическая модель психопатии (Patrick et al., 2009) |
| Бытовой садист | Бытовой садизм (Buckels et al., 2013, 2014) |
| Пограничный тип | Пограничная организация личности (Kernberg, 1967), пограничный паттерн ICD-11 |
| Тревожный тип | Тревожная привязанность (Fraley et al., 2000) |
| Избегающий тип | Избегающая привязанность (Bartholomew & Horowitz, 1991) |
| Высокочувствительный | Сенсорная чувствительность (Aron & Aron, 1997) |
| Алекситимик | Алекситимия (Taylor et al., 1997) |
| Светлая триада | Светлая триада (Kaufman et al., 2019) |

- **Архетипы** — карточки на главной, у каждой страница с научной основой, признаками и источниками.
- **Мой тип** — скрининг: 26 утверждений по 13 измерениям, ранжирование по прототипам. Формулировки собственные: валидированные шкалы защищены авторским правом (TAS-20 требует платной лицензии).
- **Флаги** — кейсы «кто перед вами».
- **Тренажёр** — диалог с ИИ-персонажем (скрытым или выбранным) и разбор от ИИ-тренера.

Это не диагностика: приложение описывает паттерны поведения.

## Картинки архетипов

Положить `public/img/archetypes/<id>.webp` (портрет 4:5) и добавить `id` в `IMAGES_READY` в `public/js/archetypes.js`. До этого показывается эмодзи на цветном градиенте.

## Запуск

```bash
npm install
DEEPSEEK_API_KEY=sk-... npm start   # http://localhost:3000
npm test
```

Без ключа тест и кейсы работают, а диалоги отключены.

## ИИ-провайдер

| `AI_PROVIDER` | Ключ | Модель | Назначение |
|---|---|---|---|
| `deepseek` | `DEEPSEEK_API_KEY` | `deepseek-flash` | демо, дёшево |
| `anthropic` | `ANTHROPIC_API_KEY` | `claude-opus-5-5` | продакшен |

Переключение — одна переменная окружения, код менять не нужно. Если `AI_PROVIDER` не задан, берётся тот провайдер, чей ключ есть (DeepSeek в приоритете).

## Деплой на Render

1. Render → **New → Blueprint** → выбрать этот репозиторий (`render.yaml` подхватится сам).
2. Ввести `DEEPSEEK_API_KEY`. Поле `ANTHROPIC_API_KEY` пока оставить пустым.
3. Поставить лимит трат у провайдера. `AI_CALLS_PER_HOUR` (по умолчанию 300) — общий лимит ИИ-запросов в час на сервер.

## Telegram Mini App

@BotFather → `/newapp` (или `/setmenubutton`) → указать URL сервиса на Render. Тема (светлая или тёмная) подхватывается из Telegram.

## Стек

Node 22, Express, DeepSeek (OpenAI-совместимый API) или `@anthropic-ai/sdk`, чистый HTML/CSS/JS, дизайн-система Claude.
